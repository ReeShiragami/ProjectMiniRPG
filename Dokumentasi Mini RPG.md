Backstory :   
Di suatu dunia yang mengandalkan pedang dan sihir dalam kehidupannya. Tersebutlah Raja Iblis sang penguasa yang bengis nan kejam. Dia adalah sosok pengendali sihir terkuat yang ada pada dunia ini. Dengan pasukannya, Raja Iblis menyerang daerah-daerah di kekuasaannya. Salah satunya adalah pemukiman ras manusia. Para manusia mau tidak mau harus turun tangan dalam menumpahkan darah mereka ke medan pertempuran. Pada akhirnya, sang Raja Iblis bersama pasukannya dapat dipukul mundur dari pemukiman tersebut. Kekuatan jahatnya tak lagi mampu menyentuh pemukiman manusia. Semenjak saat itu, manusia membangun peradabannya sendiri. Menugaskan para pemberani untuk melawan pasukan Raja Iblis.   
Suatu ketika, kekuatan Raja Iblis telah melemah. Sehingga Kaisar dari peradaban manusia memerintahkan beberapa petualang untuk mencoba mengalahkan sang Raja Iblis. Salah satu petualang tersebut adalah Fuafua. Seorang pemuda ahli pedang dan sihir. Dia bersama rekan-rekan sesama petualang ditugaskan untuk mengalahkan Raja Iblis. Mereka pun berangkat sembari dirayakan oleh para warga yang ada.    
Namun, dua tahun berlalu. Tiada kabar dari satu pun petualang yang ditugaskan mengalahkan Raja Iblis. Para warga telah kehilangan harapan bahwa mereka telah kalah dalam pertempurannya melawan Raja Iblis. Termasuk Jack, Ayah dari Fuafua.   
Jack tidak menerima anaknya telah kalah melawan Raja Iblis. Sehingga dia mempersiapkan dirinya untuk mencari anaknya sekaligus melawan Raja Iblis. Dengan sebilah pedang kecil dan kemampuannya dalam bertarung, Jack memulai petualangannya.

Arsitektur : 
Seperti Turn-Based pada umumnya. 
Satu giliran dianggap satu turns. Pemain akan mendapatkan giliran pertama untuk menyerang.   
Ada pilihan untuk mengeluarkan Skill, Basic Attack, dan Dodge.
Stats dasar meliputi HP, Defense, dan ATK. 

Rancangan Arsitektur
rpg/
 ├─ model/
 │   ├─ Character (abstract)  ← hp, def, atk, effects, endRound(), takeDamage(), heal()
 │   ├─ Player
 │   ├─ Enemy                 ← daftar Action + EnemyBehavior (data, bukan subclass per musuh)
 │   └─ Boss, BossPhase (PhaseOne, PhaseTwo)
 ├─ action/
 │   ├─ Action (interface), BasicAttack, Dodge
 │   ├─ ClawAttack (peluang Bleed), FlameAttack (peluang Burn)
 │   └─ Skill (abstract) → SayaAkanLawan, SelfRegen
 ├─ effect/
 │   ├─ StatusEffect (abstract) → AtkBuff, Regen
 │   └─ DamageOverTime (abstract) → Burn, Bleed
 ├─ item/       Item (abstract) → ZirahBesiRingan, LiontinHijau, RunePahlawan
 ├─ ai/         EnemyBehavior (interface) → AlwaysAttack, RegenChance(0.4)
 ├─ battle/     Battle, DamageFormula (interface) → FlatSubtraction,
 │              ActionChooser, BattleLog, BalanceSimulator
 ├─ story/      Scene (interface) → DialogueScene, BattleScene, RewardScene, EndingScene
 └─ Main.java
